# rest-minutes（煦煦休息時間）

康軒成績手動記帳 → 換成休息分鐘 → 倒數計時使用的靜態測試版（可愛九尾狐風）。

## 使用

用瀏覽器打開 `index.html`（或靜態伺服器根目錄）。資料存在瀏覽器本機（localStorage）。

## 規則摘要

- 85 分起 1 點；每滿多 5 分再＋1（88／89 仍＝1）
- 1 點＝5 分鐘；每科**一般**最多 20 分；全日**一般池** 60 分
- **超時／加班（預設開）**：一般池滿後若繼續記成績，超出的分鐘仍可賺進同一錢包、當天就能倒數用；設定裡可改為舊的硬上限
- 每次 100 分另外＋5 分鐘（可累加）
- 84 分及以下＝0 點
- 休息倒數結束會提示「休息時間到」並播放提示音（在按「開始休息」時解鎖音訊）
